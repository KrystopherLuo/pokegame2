# pokegame2

Um fan game em texto de outro fan game muito antigo de pokémon para windows chamado "pokégame"


Neste jogo, você começa escolhendo um starter da primeira geração e precisa treinar ele por meio de batalhas contra treinadores e batalhas selvagens para se fortalecer, capturar novos pokémons e derrotar chefes e líderes de ginásio até conseguir se tornar forte o suficiente para derrotar o chefe final da equipe Rocket, Giovanni e capturar o lendário pokémon mewtwo.
